STEP-BY-STEP GUIDE
═════════════════════════════════════════════════════════════════════════════════

STEP 1️⃣: Create GitHub Account & Repository
───────────────────────────────────────────────────────────────────────────────

If you don't have GitHub account:
  1. Go to https://github.com
  2. Click "Sign up"
  3. Create account (use your email)
  4. Verify email

Create new repository:
  1. Go to https://github.com/new
  2. Repository name: nonrootvps-railway
  3. Description: NoRoot Mod Proxy - Railway Deployment
  4. Select "Public" (Railway needs to access it)
  5. Click "Create repository"

After creation, you'll see:
  git remote add origin https://github.com/YOUR_USERNAME/nonrootvps-railway.git
  git branch -M main
  git push -u origin main


STEP 2️⃣: Prepare Your Local Machine
───────────────────────────────────────────────────────────────────────────────

Install Git (if not already installed):
  
  Windows: https://git-scm.com/download/win
  Mac: brew install git
  Linux: apt install git

Verify Git installation:
  git --version

Configure Git (first time only):
  git config --global user.email "your@email.com"
  git config --global user.name "Your Name"


STEP 3️⃣: Clone Repository to Your Machine
───────────────────────────────────────────────────────────────────────────────

Open terminal/PowerShell and run:

  git clone https://github.com/YOUR_USERNAME/nonrootvps-railway.git
  cd nonrootvps-railway

You should now have a folder with these files:
  nonrootvps-railway/
  ├── Dockerfile
  ├── railway.json
  ├── .gitignore
  ├── README.md
  ├── README_KANNADA.md
  ├── DEPLOY.sh
  ├── GITHUB_RAILWAY_SETUP.txt (this file)
  └── NONROOTVPS/
      ├── main.py
      ├── requirements.txt
      ├── ifix.config.json
      └── ... (other files)


STEP 4️⃣: Add All Files to Git
───────────────────────────────────────────────────────────────────────────────

In your terminal (in the nonrootvps-railway folder):

  git add .
  git commit -m "Initial NONROOTVPS Railway deployment"
  git push origin main

You should see:
  ✓ Files uploaded to GitHub
  ✓ Repository updated

Verify in browser:
  Go to https://github.com/YOUR_USERNAME/nonrootvps-railway
  You should see all files listed


STEP 5️⃣: Create Railway Account
───────────────────────────────────────────────────────────────────────────────

1. Go to https://railway.app
2. Click "Sign up"
3. Select "Sign up with GitHub" (easiest)
4. Authorize Railway to access GitHub
5. Complete onboarding (you can skip questions if wanted)

You're now ready to deploy!


STEP 6️⃣: Deploy to Railway
───────────────────────────────────────────────────────────────────────────────

Option A: Using Railway Dashboard (Recommended)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Go to https://railway.app/dashboard
  2. Click "New Project"
  3. Click "GitHub Repo"
  4. Search for "nonrootvps-railway"
  5. Click to select it
  6. Click "Deploy"
  
  Wait 2-5 minutes while Railway builds and deploys.


Option B: Using Railway CLI (Advanced)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  npm install -g @railway/cli
  railway login
  railway link
  railway up


STEP 7️⃣: Set Environment Variables
───────────────────────────────────────────────────────────────────────────────

In Railway Dashboard:

  1. Click your project (nonrootvps-railway)
  2. Go to "Variables" tab
  3. Click "Add Variable"
  4. Add these (one by one):

     ┌─────────────────────────────────────────┐
     │ PORT         │ 8089                      │
     ├─────────────────────────────────────────┤
     │ RAILWAY_HOST │ 0.0.0.0                   │
     ├─────────────────────────────────────────┤
     │ TELEGRAM_BOT_TOKEN │ your_bot_token     │
     ├─────────────────────────────────────────┤
     │ TELEGRAM_ADMIN_ID  │ your_admin_id      │
     └─────────────────────────────────────────┘

  5. Click "Save"
  
  Railway automatically restarts your app with new variables!


STEP 8️⃣: Access Your Service
───────────────────────────────────────────────────────────────────────────────

After deployment is complete:

Railway gives you a public URL. Find it in:
  Dashboard → Your Project → "Public Domain"

Example:
  https://nonrootvps-railway-prod.up.railway.app

Your mitmproxy service is accessible at:
  https://nonrootvps-railway-prod.up.railway.app:8089

Test it:
  curl https://your-railway-url:8089


STEP 9️⃣: Monitor Your App
───────────────────────────────────────────────────────────────────────────────

Dashboard features:

  Logs: Click "Logs" tab to see real-time output
  Metrics: CPU, Memory, Network usage
  Restart: If app crashes, click "Restart"
  Status: Green = healthy, Red = error

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

❌ "Build failed" in Railway
───────────────────────────────────────────────────────────────────────────────
Check Railway Logs:
  Dashboard → Logs tab → Look for red error messages

Common causes:
  • Missing dependencies in requirements.txt (already included ✓)
  • Port conflicts (use PORT env var ✓)
  • File permissions (Dockerfile handles this ✓)

Solution: Check logs, fix issue, push to GitHub:
  git add .
  git commit -m "Fix build issue"
  git push origin main
  Railway auto-rebuilds


❌ "App not responding" or crashing
───────────────────────────────────────────────────────────────────────────────
1. Check Railway Logs for error messages
2. Look for this line in logs:
   "[*] Starting Mitmproxy Interceptor Server on port 8089..."
3. If not there, something went wrong

Fix:
  • Check NONROOTVPS/main.py is not corrupted
  • Verify requirements.txt is complete
  • Check environment variables are set correctly


❌ "Database not persisting"
───────────────────────────────────────────────────────────────────────────────
Railway's default storage is temporary. To keep database:

  1. Dashboard → "Volumes" tab
  2. Click "Add Volume"
  3. Mount path: /tmp/nonrootvps
  4. Size: 1GB
  5. Save

Now your database persists across restarts!


❌ "Port 8089 already in use"
───────────────────────────────────────────────────────────────────────────────
Change PORT variable in Railway:
  1. Dashboard → Variables
  2. Change PORT to 9000 (or any free port)
  3. Save
  4. App restarts automatically

Prevents sensitive files from being pushed to GitHub:
